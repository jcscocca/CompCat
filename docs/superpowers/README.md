# Historical design and implementation record

Everything under `specs/` and `plans/` is a point-in-time record of how CompCat features were
designed and built. It is retained for provenance and decision history, not as current product or
operational documentation. Many entries intentionally describe retired Waypoint, routes,
LocalAgent, and pre-launch behavior, and may link to source files that no longer exist.

Start with the [canonical documentation index](../README.md) for the current architecture, API,
assistant, deployment posture, and roadmap. Do not update historical plans to match current code;
record new current-state decisions in the canonical docs instead.
